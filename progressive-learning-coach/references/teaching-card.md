# Teaching Card

Every daily card should be small enough to complete in one sitting.

## Required Sections

1. Today's topic.
2. Why learn it now.
3. Core explanation.
4. Minimal example, case, sentence, code snippet, or source excerpt.
5. Explanation of the example.
6. Personalized reminder based on `question-log.md`.
7. One simple exercise.
8. Completion instruction.

## Concept Density

Introduce one new target concept. Surrounding material should be already learned or deliberately simplified.

For programming topics:

- Prefer self-contained snippets when real code contains too many unlearned concepts.
- If using real code, explicitly name the single target concept and avoid explaining unrelated syntax unless it is already learned.
- Do not hide advanced prerequisites inside the example.

For non-programming topics:

- Use a short realistic example rather than a broad lecture.
- Make the exercise concrete and checkable.
- Reuse the learner's recent mistakes or questions gently.

## Pending Reminder Format

When a pending topic exists, send a continuation reminder instead of a new card:

- Name the pending topic.
- Briefly restate the key idea.
- Mention the likely stuck point from the question log.
- Tell the learner how to complete it.
